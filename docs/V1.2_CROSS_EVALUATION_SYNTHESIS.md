# AidLens V1.2 — Cross-Evaluation Evidence Synthesis

V1.2 moves AidLens from evaluation-level grouping toward cross-evaluation evidence intelligence while preserving the validated V1.1 retrieval and ranking contract.

## Product question

The V1.2 interface should help a user answer:

- Which kinds of evidence recur across the returned evaluations?
- Which locations, institutions, and thematic metadata recur?
- Which evaluations appear contextually similar enough to inspect side by side?
- Where is outcome evidence present or absent in the returned result set?

It must not manufacture an answer to “what works” by converting metadata overlap into an effect claim.

## Frozen retrieval and ranking contract

V1.2 does not retune ranking:

- first stage: `BAAI/bge-base-en-v1.5`
- reranker: AidRanker V1
- Torch serving backend
- AidRanker batch size: `8`
- candidate pool: `40`
- fusion alpha: `0.50`
- production `top_k`: `10`
- default diversity cap: max 3 passages per evaluation

The new synthesis layer runs only after the final ranked/diversified hits have been selected.

## Result-set synthesis

`EvidenceSearchResponse.synthesis` is additive and deterministic. Existing flat `hits` and evaluation-level `groups` remain backward compatible.

The synthesis contains:

### Evidence-role coverage

For each evidence role represented in the final hits, AidLens reports:

- number of evaluations containing that role
- number of returned passages carrying that role

The role taxonomy remains the conservative V1.0 section mapping. `executive_summary` and unknown sections remain `supporting` rather than being promoted to outcomes.

### Recurring facets

AidLens aggregates structured evaluation metadata across the returned evaluation groups:

- location
- institution
- keyword

A facet appears only when it occurs in at least two returned evaluations. Matching is case-insensitive and whitespace-normalized, while the first observed display form is retained.

These are co-occurrence signals, not causal themes.

### Transferability context overlap

For each pair of returned evaluations with at least one shared structured signal, AidLens computes a metadata-Jaccard overlap using category-qualified tokens such as:

- `location:kenya`
- `institution:usaid`
- `keyword:education`

The response includes the shared locations, institutions, and keywords plus the overlap score. Only the ten strongest non-zero pairs are returned.

This is deliberately called **context overlap**, not a transferability score. Similar metadata does not establish that an intervention will transfer, and dissimilar metadata does not establish that it will not.

## What V1.2 does not infer

V1.2 does not infer:

- positive vs negative effect direction
- supporting vs contradictory stance
- causal effectiveness
- generalizability
- intervention transferability
- generated outcome summaries

Those require a later structured claim-extraction layer with passage-level provenance and explicit stance/effect handling.

## Response caveats

The API returns caveats alongside every synthesis, including:

1. the synthesis covers only the final ranked result set, not the full corpus;
2. recurring facets are metadata co-occurrence, not causal “what works” claims;
3. context overlap is a similarity signal, not a transfer verdict;
4. V1.2 does not infer supporting or contradictory effect stance.

## UI

The search experience adds a cross-evaluation evidence map above the source evaluation cards. It shows:

- evaluations compared
- evaluations with returned outcome/sustainability evidence
- recurring structured signals
- evidence-role coverage
- strongest context-overlap pairs

Every evaluation card and ranked passage remains directly visible below the synthesis so the user can inspect the source evidence rather than relying on a generated conclusion.

## Next layer

A future milestone can add passage-grounded claim extraction for intervention/outcome statements. Only after claims have stable source provenance should AidLens introduce support/contradiction clustering and a stronger “What Works?” synthesis surface.
